# はじめに

RenoP は、個人やチーム向けの軽量で素早く展開できる **セルフホスト Maven サーバー**です。

次の点に注力しています。

- 妥当なデフォルトによる素早いセットアップ
- Release / Snapshot / Private リポジトリ
- ローカルキャッシュ付きの Maven ミラープロキシ
- 閲覧・アップロード・ユーザー・トークン・ヘルス用の小さな Web UI

**公開ホスティング**を主目的として使う想定には、現時点では最適化されていません。

## 設計目標

| 目標             | 意味                                               |
|------------------|----------------------------------------------------|
| シンプルな運用   | 単一バイナリ、作業ディレクトリ内の設定ファイル     |
| Maven ネイティブ | 標準リポジトリレイアウトとクライアント互換         |
| 透明性           | 広告なし、製品テレメトリなし、コミュニティ版は無料 |
