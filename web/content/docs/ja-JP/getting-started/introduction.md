# はじめに

RenoP はセルフホストの Maven サーバーです。

- Release / Snapshot / Private リポジトリ
- ローカルキャッシュ付きの上流ミラープロキシ
- Web UI：閲覧、アップロード、ユーザー、トークン、ヘルス

公開マルチテナントホスティングは今のところ対象外です。

## 方針

| 項目                 | 内容                                         |
|----------------------|----------------------------------------------|
| 運用が単純           | 単一バイナリ、作業ディレクトリに設定         |
| Maven レイアウト     | 標準のリポジトリパス、通常のクライアントで可 |
| 余計なものを載せない | 広告なし、製品テレメトリなし、無料           |
