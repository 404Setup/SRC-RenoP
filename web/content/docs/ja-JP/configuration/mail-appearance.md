# メールの外観

メールテンプレートには RenoP と同じ青い操作ボタン、角丸カード、中立色の背景、システムフォントを使います。
サイト名はメッセージの上、確認コードは独立したパネルに表示し、追加情報は本文と区切ります。
プレーンテキスト版にも同じメッセージと操作 URL を含めます。

## プリセットの選択

`mail.template_style` を設定するか、メール設定ページでスタイルを選択します。

```yaml
mail:
  template_style: card
```

- `card`：余白のある標準カード。
- `compact`：本文の余白と見出しを小さくしたカード。
- `notice`：上端に琥珀色の線を付けた標準カード。

シーン ID とアカウント言語の選択は変わりません。外部の画像、フォント、スクリプト、スタイルシートは不要です。
インラインの色指定が基本の外観を定め、受信クライアントが対応する場合にレスポンシブ表示とダークモードを適用します。
ユーザーのテキストは引き続きエスケープし、操作 URL は設定したインスタンスに限定します。

## プレビューと配信

管理者はメール設定から実際に送信せずにシーンを確認できます。
GET /api/settings/mail/templates/:scene?style=card は件名、HTML、プレーンテキストを返します。
プレビューは要求の `Accept-Language` に従い、アカウント通知は受信者の保存済み言語を使い、既定は英語です。
サンプル値を使用するため、保存済みの資格情報はプレビューに含みません。

変更したテンプレートは新しいメッセージが送信キューへ入るときに適用します。すでにキューにあるメッセージは
ジョブに保存された描画済み内容を維持します。配信上限、クレジット予約、状態確認、中断した送信を再試行しない規則は
変わりません。プロバイダーとキューの設定は[メール配信](mail.md)を参照してください。
