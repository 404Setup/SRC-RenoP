# トークン & ユーザー API

- `GET /api/tokens` - トークン一覧
- `POST /api/tokens` - トークン作成
- `DELETE /api/tokens/:id` - トークン失効
- `GET /api/auth/users` - ユーザー一覧 (Manager/Admin)
- `POST /api/auth/users` - ユーザー作成
- `DELETE /api/auth/users/:username` - ユーザー削除
