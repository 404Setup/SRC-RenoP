# HTTP API RenoP

RenoP предоставляет HTTP API для автоматизации администрирования, интеграции клиентов и мониторинга. По умолчанию
сервер слушает `http://localhost:3000`.


Отдельная [страница API](/api) переключается между Markdown RenoPAPI и OpenAPI. Ссылки вида `/api/authentication` открывают статью; `?view=openapi` выбирает спецификацию. Локальный просмотрщик загружается по запросу и не выполняет вызовы API. Исходный [файл OpenAPI](/assets/openapi.yaml) доступен для скачивания. Категория API исключена из общей документации; старые ссылки `/docs/api/...` перенаправляются на `/api/...`.

## Структура маршрутов

| Префикс                          | Назначение                                                        |
|:---------------------------------|:------------------------------------------------------------------|
| `/api/*`                         | Управление аутентификацией, аккаунтами, настройками и сообщениями |
| `/{repo}/*`                      | Загрузка, скачивание и удаление с учётом формата репозитория      |
| `/{npm-repo}/*`                  | Packument npm, tarball, публикация, dist-tag и поиск              |
| `/index/*` или `/{repo}/index/*` | Cargo Sparse Index                                                |
| `/v2/*`                          | Docker и OCI Distribution v2                                      |
| `/javadoc/*`                     | Изолированный просмотр Javadoc                                    |
| `/cargodoc/*`                    | Изолированный просмотр Cargodoc                                   |

## Форматы данных и Protobuf

API управления на основе схем поддерживают JSON (`application/json`) и бинарный protobuf (`application/x-protobuf`
или `application/protobuf`). `Content-Type` выбирает декодирование запроса, `Accept` — формат ответа. Если `Accept`
отсутствует или не поддерживается, ответ остаётся в protobuf для старых клиентов. Тело без указанного типа также
декодируется как protobuf. Определения сообщений находятся в `proto/api/v1/api.proto`.

JSON использует исходные имена snake_case; на входе также принимаются имена camelCase protobuf. 64-битные целые
передаются десятичными строками, байты — строками Base64. Неизвестные и повторяющиеся JSON-поля отклоняются. Лимит
запроса остаётся 1 MiB, с сохранением меньших лимитов отдельных endpoints. Форматы реестров, бинарные части загрузок,
текст проверки здоровья и форматы ошибок остаются прежними.

## Способы аутентификации

- **Cookie браузера**: `renop_session=<session_id>`. Секрет HttpOnly не принимается в заголовках или URL.
- **Bearer API Token**: `Authorization: Bearer <token>`. Возможности Token всегда пересекаются с текущими правами
  аккаунта.
- **Basic Auth для пакетных протоколов**: `Authorization: Basic <base64(user:password_or_token)>`.

Basic Auth не позволяет обращаться к API управления. Учётные данные в URL и `Authorization: Session` отклоняются.

## Основные коды HTTP

| Код                       | Значение            | Назначение                                         |
|:--------------------------|:--------------------|:---------------------------------------------------|
| `200 OK`                  | Успех               | Успешный ответ с телом                             |
| `201 Created`             | Создано             | Ресурс или загрузка инициализированы               |
| `204 No Content`          | Успех               | Успешный ответ без тела                            |
| `400 Bad Request`         | Неверный запрос     | Некорректные параметры или тело                    |
| `401 Unauthorized`        | Нет аутентификации  | Учётные данные отсутствуют или неверны             |
| `403 Forbidden`           | Доступ запрещён     | Недостаточно прав или IP временно заблокирован     |
| `404 Not Found`           | Не найдено          | Ресурс отсутствует                                 |
| `409 Conflict`            | Конфликт            | Несовместимое состояние или ресурс уже существует  |
| `429 Too Many Requests`   | Ограничение частоты | Превышена допустимая частота запросов              |
| `503 Service Unavailable` | Временно недоступно | Перегрузка или временная недоступность зависимости |
