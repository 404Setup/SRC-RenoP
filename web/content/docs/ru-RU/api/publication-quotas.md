# Квоты публикаций

Квоты ограничивают число локально загруженных файлов, их суммарный размер и число завершённых публикаций проектов.
По умолчанию новая установка разрешает 600 файлов, 40 МиБ и 20 публикаций в месяц. Системный администратор может
изменить общие значения или задать отдельные настройки аккаунта либо глобальной команды.

## Политика

`period` принимает `day`, `week` или `month`; границы рассчитываются по UTC. Нулевой лимит допустим только в настройке
владельца и запрещает соответствующую операцию. Параметр `unlimited` доступен только администратору и отключает расход
квоты. Пустой объект настройки восстанавливает все глобальные значения.

## Владение

Личный пакет расходует квоту публикующего аккаунта. Пакет или домен Maven, привязанный к глобальной команде, расходует
только квоту команды. Передача владения меняет владельца квоты для будущих публикаций и не переносит историю. Загрузки и
обновления каталога из зеркала квоту не расходуют.

## Учёт использования

Cargo и npm учитывают один сохранённый файл и одну публикацию для принятой версии. Docker учитывает manifest, config и
описатели слоёв, а публикацию завершает при отправке manifest. Maven учитывает каждый клиентский PUT как файл и одну
публикацию при принятии POM. Файловый движок учитывает каждый PUT как файл и публикацию. Созданные сервером индексы и
контрольные суммы отдельно не учитываются.

Параллельная загрузка сначала создаёт временное устойчивое резервирование. После успешной проверки оно подтверждается;
заброшенное резервирование освобождается или удаляется обслуживанием. Состояние включает подтверждённое использование и
активные резервы, поэтому параллельные запросы не могут превысить лимит.

## Конечные точки

```http
GET /api/publication-quota
GET /api/publication-quota/users/{username}
PUT /api/publication-quota/users/{username}
GET /api/publication-quota/super-teams/{prefix}
PUT /api/publication-quota/super-teams/{prefix}
GET /api/settings/publication-quota
PUT /api/settings/publication-quota
```

Аккаунт читает собственное состояние, а участники команды — состояние команды. Только системный администратор может
просматривать другой аккаунт, менять настройки, включать `unlimited` или изменять глобальные значения.

## Применение

При исчерпании квоты возвращается `429 Too Many Requests`. Заголовок `X-Renop-Error-Code` содержит
`publication_file_quota`, `publication_byte_quota` или `publication_count_quota`. Проверка выполняется после
аутентификации,
проверки прав, резервирования пакета, привязки пространства имён и проверки домена Maven и не выдаёт дополнительных
прав.
