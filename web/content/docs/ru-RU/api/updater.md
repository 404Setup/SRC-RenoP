# API встроенного обновления

Изменяющие операции требуют сессию администратора или API Token с `admin:updates`. Ошибки возвращаются в JSON с
заголовком `X-Renop-Error-Code`, поэтому клиент может локализовать их без вывода внутренних путей и сетевых деталей.

## Чтение состояния

`GET /api/updater/status` возвращает protobuf `UpdateState`. Возможные состояния: `idle`, `checking`, `available`,
`downloading`, `ready_to_restart` и `error`. Во время онлайн-установки опрашивайте этот маршрут для получения прогресса.

## Проверка настроенного канала

`POST /api/updater/check?channel=release|nightly` возвращает JSON `CheckResult`. Необязательный параметр меняет канал
только для данного запроса. Результат содержит цель, SHA-256, размер, примечания и сохранённый диапазон изменений от
текущей версии до целевой.

## Запуск онлайн-установки

`POST /api/updater/install` запускает в фоне ограниченное скачивание, проверку хеша, распаковку Brotli/ZIP и проверку
бинарного файла. Успешный ответ — `{"status":"started"}`; процесс автоматически не перезапускается.

Прогресс скачивания показывается временным Toast и не сохраняется в центре сообщений. Результаты проверки и ошибки
остаются уведомлениями администраторов.

## Установка офлайн-пакета

`POST /api/updater/upload` принимает multipart-поле `file` или `package` с новым сырым `.br` либо прежним `.zip`.
Для больших файлов используйте блочную загрузку с `purpose=updater` и завершайте её через
`POST /api/upload/chunked/{upload_id}/complete`.

Сервер потоково обрабатывает пакет во временном хранилище с ограниченным размером, проверяет платформу бинарного файла
и возвращает `ready_to_restart`. Внутренние пути в ошибках не раскрываются.

## Перезапуск

`POST /api/updater/restart` применяет подготовленный бинарный файл, если он есть, и перезапускает RenoP. Соединение
может закрыться до получения JSON `{"status":"restarting"}`. Официальный интерфейс показывает Toast перед перезапуском.

## Стабильные коды ошибок

Заголовок `X-Renop-Error-Code` может содержать `forbidden`, `insufficient_space`, `missing_file`, `install_busy`,
`invalid_package`, `incompatible_binary`, `package_too_large`, `package_processing_failed`, `check_failed`,
`notification_failed` или `restart_failed`.
