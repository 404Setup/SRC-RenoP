# API статистики скачиваний

RenoP агрегирует успешные скачивания пакетов, не сохраняя отдельную строку для каждого запроса. Счётчики содержат
число скачиваний, логический объём и время последнего обновления. Пользователь привязан к неизменяемому ID аккаунта,
поэтому смена имени не разделяет историю.

Репозитории Maven, Cargo и Docker ведут учёт по умолчанию. Неструктурированный движок `files` включается явно. Запросы
контрольных сумм, отделённых подписей, метаданных Maven и файлов Javadoc исключаются. `HEAD`, `304`, неуспешные запросы
и не начальные диапазоны не учитываются. Docker записывает одно скачивание при возврате манифеста, а не для каждого blob.

## Запросы аккаунта

`GET /api/statistics` возвращает статистику владельца API Token. `GET /api/statistics/users/:username` использует ту же
границу аккаунта; для другого аккаунта нужен Token системного администратора.

Оба маршрута принимают только Bearer API Token с `statistics:read`. Cookie браузерной сессии и Basic отклоняются.
Перед запросом счётчики из памяти записываются в базу, поэтому ответ включает скачивания, уже принятые текущим процессом.

## Системные запросы

`GET /api/statistics/system` требует аккаунт системного администратора и область `admin:statistics`. Доступны группировки
`user`, `repository`, `namespace`, `package` и `version`. Маршруты аккаунта поддерживают все группировки, кроме `user`.

Необязательные точные фильтры: `username` (только system), `repository`, `format`, `namespace`, `package` и `version`.
Пагинация использует `limit` от 1 до 100 и `offset` от 0 до 1 000 000. Страница также содержит общие `count` и `bytes`
для всего фильтра, а также полное число групп.

## Настройки репозитория

Администратор читает действующие переключатели через `GET /api/settings/repositories/download-statistics` и изменяет
репозиторий через `PUT /api/settings/repositories/:name/download-statistics`. JSON-тело имеет вид `{"enabled": true}`
или `{"enabled": false}`.

`DELETE /api/settings/repositories/:name/download-statistics` безвозвратно удаляет сохранённые и ожидающие счётчики.
Для Docker также сбрасывается совместимый pull count на страницах образов. При удалении репозитория его статистика
очищается автоматически.

Полные схемы ответов и ограничения приведены в `web/assets/openapi.yaml`.
