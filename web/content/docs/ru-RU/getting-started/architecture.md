# Архитектура системы

- **Потоковый ввод-вывод**: Передача артефактов напрямую между сокетом и хранилищем без буферизации целых файлов в
  памяти.
- **Единый уровень БД**: Поддержка SQLite, MySQL и PostgreSQL (через `pgx/v5`).
- **Атомарность**: Запись во временные файлы `.tmp` с последующим атомарным переименованием.
- **Карантин GPG**: Артефакты без подтвержденной подписи изолируются в `.renop.tmp.gpg`.
