# Введение

RenoP — self-hosted Maven-сервер.

- Репозитории release, snapshot и private
- Прокси upstream-зеркал с локальным кэшем
- Веб-интерфейс: просмотр, загрузка, пользователи, токены, health

Публичный multi-tenant хостинг пока не цель.

## Цели

| Цель                 | Смысл                                              |
|----------------------|----------------------------------------------------|
| Простая эксплуатация | Один бинарник; конфиг в рабочей директории         |
| Раскладка Maven      | Стандартные пути; обычные клиенты работают         |
| Без лишнего          | Без рекламы, без продуктовой телеметрии, бесплатно |
