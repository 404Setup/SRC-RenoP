# Введение

RenoP — лёгкий, быстро разворачиваемый **самохостируемый Maven-сервер** для частных лиц и команд.

Он ориентирован на:

- Быстрый старт с разумными значениями по умолчанию
- Репозитории release, snapshot и private
- Проксирование Maven-зеркал с локальным кэшем
- Небольшой веб-интерфейс для просмотра, загрузок, пользователей, токенов и состояния

Если планируется **публичный хостинг**, RenoP сейчас не ставит этот сценарий в приоритет.

## Цели проектирования

| Цель                 | Смысл                                                                  |
|----------------------|------------------------------------------------------------------------|
| Простая эксплуатация | Один бинарник, конфигурация в рабочей директории                       |
| Maven-native         | Стандартная раскладка репозиториев и совместимость с клиентами         |
| Прозрачность         | Без рекламы, без продуктовой телеметрии, бесплатная community-редакция |
