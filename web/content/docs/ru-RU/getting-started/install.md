# Установка и сборка

## 1. Загрузка бинарных файлов

- **Стабильная ветка (Stable)**: `https://mvnc.pkg.one/update/renop/stable/`
- **Ночная ветка (Nightly)**: `https://mvnc.pkg.one/update/renop/nightly/`

## 2. Уровни микроархитектуры x86-64

| Уровень                         | Инструкции                          | Сценарий применения                                                      |
|:--------------------------------|:------------------------------------|:-------------------------------------------------------------------------|
| **x86-64-v1**                   | Базовый набор 64-bit                | Совместим со всеми 64-битными CPU x86                                    |
| **x86-64-v2**                   | SSE3, SSSE3, SSE4.1, SSE4.2, POPCNT | Процессоры с 2008 года выпуска                                           |
| **x86-64-v3** *(Рекомендуется)* | AVX, AVX2, BMI1, BMI2, FMA3         | Intel Haswell (2013+), AMD Zen 2 (2019+). **Рекомендуется для серверов** |
| **x86-64-v4**                   | AVX-512                             | Серверы с поддержкой AVX-512                                             |
| **ARM64**                       | NEON, Crypto                        | Apple Silicon, AWS Graviton и ARM64 Linux                                |

## 3. Проверка и запуск

```bash
# Проверка контрольной суммы
sha256sum -c SHA256SUMS --ignore-missing

# Запуск
./renop
```

## 4. Установка как системной службы

```bash
# Установка и автозапуск
./renop --install

# Удаление службы
./renop --uninstall
```
