# Модель безопасности

- **Anonymous**: Только чтение репозиториев PUBLIC
- **User**: Доступ в соответствии с разрешениями (`canview:{repo}`, `canupdate:{repo}`)
- **Manager / Admin**: Управление системой и пользователями
