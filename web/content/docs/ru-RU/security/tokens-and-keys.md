# API-токены и GPG

- **API-токены**: Именованные 256-битные учётные данные с областями доступа и необязательным сроком действия. Секрет
  показывается один раз, а в базе хранится только его SHA-256-дайджест.
- **Авторизация**: Запрос ограничивается одновременно областями токена и текущими правами его владельца. Отзыв
  применяется немедленно.
- **Передача**: Для API используйте `Authorization: Bearer <token>`. Basic разрешён только протоколам пакетов;
  Session-заголовки и учётные данные в URL отклоняются.
- **GPG**: Проверка `.asc` подписей и карантин `.renop.tmp.gpg`.
