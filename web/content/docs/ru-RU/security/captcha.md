# Проверка безопасности

## Провайдеры и области

Настройте CAPTCHA на странице проверки безопасности. Поддерживаются отключение, reCAPTCHA v2 с флажком, невидимая v2, v3, Cloudflare Turnstile, hCaptcha и Friendly Captcha v2. Используйте соответствующие ключ сайта и секретный/API-ключ.

Отдельно включаются вход по паролю, регистрация, ручная почта, создание глобальных команд, доменов публикации и пакетов. Passkey и внешние входы не затрагиваются настройкой пароля. Для регистрационного письма приоритетна ручная почта, иначе проверяется регистрация. Завершение регистрации является отдельным действием.

Проверки относятся к интерактивным и анонимным действиям. Проверенные API-токены и пароли протоколов исключены по действительным учётным данным, а не User-Agent. Браузерная загрузка Maven и инициализация частей проверяют новые пакеты. Существующие пакеты и разрешённая автоматизация сохраняют прежние права.

Секреты не возвращаются. Пустое поле сохраняет ключ при неизменных провайдере и ключе сайта; изменение любого из них, включая отключение, удаляет старый секрет. Порог v3 по умолчанию равен 0.5. Разрешите имя сайта в доменах сервера и у провайдера. Friendly Captcha поддерживает глобальный и европейский сервисы.

reCAPTCHA и Turnstile проверяют имя хоста. hCaptcha проверяет ожидаемый ключ сайта, поскольку имя хоста используется только для статистики. Friendly Captcha проверяет ключ сайта и источник, если провайдер его возвращает.

```yaml
captcha:
  provider: turnstile
  site_key: YOUR_SITE_KEY
  secret_key: YOUR_SECRET_KEY
  min_score: 0.5
  friendly_region: global
  scopes:
    password_login: true
    registration: true
    manual_mail: true
    super_team_create: false
    domain_create: false
    package_create: false
```

## Проверка браузера

Сторонний код загружается в отдельный фрейм только после разрешения необязательной проверки в настройках cookie. Отмена, переход и отзыв согласия удаляют фрейм. Успешная серверная проверка обязательна; ошибки, низкие оценки, неверные действия и домены отклоняются.

Браузер повторяет запрос один раз только после явного требования CAPTCHA, выданного до начала операции. Сетевые ошибки, неизвестный результат отправки письма и другие сбои не вызывают автоматический повтор.

## Контракт API

`GET /api/captcha` возвращает публичные параметры и необходимый HttpOnly cookie nonce. `POST /api/captcha/verify` принимает JSON-поля `scope`, `provider`, `site_key`, `response`; ответ CAPTCHA ограничен 16 KiB, тело JSON — 32 KiB. Успех возвращает одноразовый `proof` сроком 120 секунд.

Передайте доказательство в `X-Renop-Captcha` с теми же cookie браузера. Оно привязано к области, сеансу и текущей конфигурации. Отсутствие даёт `428`, `X-Renop-Error-Code: captcha_required` и `X-Renop-Captcha-Scope`; неверное или повторное доказательство — `400`, сбой провайдера — `503`.

`GET /api/settings/captcha` и `PUT /api/settings/captcha` требуют прав управления настройками и используют JSON. Секреты не выдаются. Изменения действуют немедленно и аннулируют ожидающие доказательства.
