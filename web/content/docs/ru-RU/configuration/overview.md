# Обзор конфигурации

Файлы конфигурации и состояние выполнения хранятся в рабочей директории процесса. Пути можно переопределить переменными
окружения.

## Файлы

| Файл                | Переменная окружения | Назначение                                                                    |
|---------------------|----------------------|-------------------------------------------------------------------------------|
| `config.yaml`       | `RENOP_CONFIG`       | Адрес прослушивания, TLS, брендинг UI, путь хранилища, updater                |
| `repositories.yaml` | `RENOP_REPOSITORIES` | Репозитории, зеркала, S3 на репозиторий                                       |
| `tokens.yaml`       | `RENOP_TOKENS`       | Пользователи, роли, upload-токены                                             |
| `index.json`        | `RENOP_INDEX`        | Кэш индекса артефактов                                                        |
| `sessions.bin`      | `RENOP_SESSIONS`     | Браузерные сессии входа (устаревший `sessions.json` мигрируется при загрузке) |

Связано с выполнением:

| Переменная                     | По умолчанию | Назначение                           |
|--------------------------------|--------------|--------------------------------------|
| `RENOP_DEFAULT_ADMIN_PASSWORD` | генерируется | Пароль первой учётной записи `admin` |

## Структура `config.yaml`

### `storage_path`

Корневой каталог локального хранилища артефактов. Относительный путь по умолчанию — `storage`.

### `server`

| Ключ                  | По умолчанию      | Описание                                                                    |
|-----------------------|-------------------|-----------------------------------------------------------------------------|
| `host`                | `0.0.0.0`         | Адрес прослушивания                                                         |
| `port`                | `3000`            | Порт прослушивания                                                          |
| `ssl_enabled`         | `false`           | Включить TLS                                                                |
| `ssl_cert_path`       | `""`              | Путь к сертификату при включённом TLS                                       |
| `ssl_key_path`        | `""`              | Путь к закрытому ключу при включённом TLS                                   |
| `domains`             | `[localhost]`     | Публичные имена хостов экземпляра (UI / метаданные и CORS по умолчанию)     |
| `cors_origins`        | `[]`              | Список CORS для браузера (пусто = только `domains`; `*` = любой origin)     |
| `enable_compression`  | `false`           | Включить сжатие HTTP-ответов                                                |
| `file_cache_size_mb`  | `16`              | Размер файлового кэша в памяти (МБ)                                         |
| `max_active_requests` | `512`             | Максимум одновременных запросов (при перегрузке — 503)                      |
| `trusted_proxies`     | `[]`              | Дополнительные CIDR/IP reverse proxy (loopback всегда считается доверенным) |
| `cdn_ip_header`       | `X-Forwarded-For` | Заголовок IP клиента за доверенным прокси (например `CF-Connecting-IP`)     |

#### CORS (`server.cors_origins`)

Определяет, какие значения `Origin` браузера могут обращаться к серверу cross-origin. Cookie сессии возвращаются с
`Access-Control-Allow-Credentials`.

| Значение                  | Эффект                                                                                |
|---------------------------|---------------------------------------------------------------------------------------|
| *(пусто)*                 | Только origins, чей хост совпадает с одним из `server.domains` (любая схема или порт) |
| `*.pkg.one`               | Вершинный домен `pkg.one` и любые поддомены (например `mvnc.pkg.one`)                 |
| `https://app.example.com` | Точное совпадение полного origin (схема, хост и порт)                                 |
| `partner.example.com`     | Указанный хост с любой схемой или портом                                              |
| `*`                       | Разрешить любой origin                                                                |

Устаревшие конфигурации с формой единственного числа `domain: example.com` по-прежнему загружаются и мигрируют в
`domains: [example.com]`.

После изменения `host`, `port` или параметров TLS требуется перезапуск процесса.

### `frontend`

Поля брендинга встроенного браузера репозитория:

| Ключ                   | Описание                                   |
|------------------------|--------------------------------------------|
| `id`                   | Идентификатор frontend / сайта             |
| `title`                | Заголовок страницы                         |
| `description`          | Краткое описание                           |
| `organization_website` | URL организации или продукта               |
| `organization_logo`    | Путь к логотипу (например `/svg/logo.svg`) |
| `background_url`       | Необязательный URL фонового изображения    |
| `icp_license`          | Необязательный ICP / compliance-текст      |

### `updater`

| Ключ      | По умолчанию | Описание                                                              |
|-----------|--------------|-----------------------------------------------------------------------|
| `channel` | `release`    | `release` или `nightly`                                               |
| `mode`    | `manual`     | Способ применения обновлений (например ручная установка в интерфейсе) |

Страница [Загрузки](/download) на сайте и обновления внутри экземпляра используют один и тот же класс источников
stable / nightly.

## Интерфейс управления

Учётные записи с правами **manager** или **admin** могут изменять большинство параметров в разделах Settings и
Repositories. Некоторые изменения конфигурации требуют перезагрузки или перезапуска процесса после записи файла. См.
описание каждого домена конфигурации.

## Хранилище

- **Локальный диск** по пути `storage_path` (режим по умолчанию)
- **S3-совместимое** объектное хранилище, настраиваемое на репозиторий в `repositories.yaml`

При загрузке могут создаваться sidecar-файлы контрольных сумм MD5 / SHA-1 / SHA-256 / SHA-512.

О видимости, зеркалах и полях S3 см. [Репозитории и зеркала](./repositories.md).
