# 行为日志与消息中心

行为日志与用户消息用途不同。行为日志回答是谁执行了安全相关操作；消息向受影响用户展示本地化结果或工作流。
二者均为数据库中的持久数据。

## 行为日志

后端使用单一注册表中的稳定操作标识。前端校验要求每个已注册操作在全部支持语言中具有翻译。

### 记录的事件

- 登录成功/失败、密码修改、账号恢复与登录方式变更；
- API Token 创建/撤销与会话撤销；
- 用户、角色、存储库、存储、代理与更新管理；
- Maven 域验证/团队变更与 npm/Cargo/Docker 包团队生命周期；
- 上传、删除、GPG 隔离/发布及其他包修改。

记录包含主体、适用时的执行者、认证方式、会话公开 ID、客户端 IP、时间与有界详情。保留时间与最大行数为全局
配置，只有授权用户可读取或清理。

## 消息中心

消息支持分页、未读数量、单条/全部已读、删除及 `pending` 工作流操作。

### 消息类别与隐私

- **公告**：管理员向指定或全部账号发送的消息；
- **工作流**：团队邀请、GPG 结果及要求决定的操作；
- **协作**：成员关系变更与中性移除通知；
- **系统结果**：更新可用与持久失败；临时下载/重启进度继续使用 Toast。

团队移除消息会说明存储库及包或 Maven 域，但刻意省略执行者。去重键避免重复检查刷屏。未读数量同时显示在
账号菜单与导航头像旁。
