# 审计日志与消息中心

RenoP 内置了审计事件流与用户消息中心，用于跟踪系统敏感操作并向用户发送工作流通知。

## 1. 安全审计日志

所有敏感管理与安全事件均会被记录至审计日志中。管理人员可通过 Web 界面或 API 查看历史审计记录。

### 记录的典型安全事件

- 用户登录成功 / 登录失败
- 密码修改与重置
- 用户账户创建、修改与删除
- 访问令牌（PAT / 上传令牌）创建与吊销
- 仓库关键配置变更
- 系统服务更新与关键参数重载

审计日志持久化于数据库中，支持按时间区间与事件类型进行过滤。

---

## 2. 用户消息中心

消息中心用于向用户推送通知并管理站内消息。

### 消息类型

1. **系统通知 (System Announcements)**：管理员向全站或特定用户广播的维护、升级或政策通知。
2. **工作流事件 (Workflow Events)**：如 CI 部署完成、GPG 签名验签通过或失败通知。
3. **团队协作 (Team Collaborations)**：仓库协作者邀请与权限变更提醒。

### 消息读取与状态流转

- 用户登录 Web 界面后，右上角会显示当前未读消息计数。
- 用户可点击单条消息进行查看并自动标记为已读，或执行「全部标记为已读」。
- 支持通过 HTTP API 批量查询消息与拉取未读数。详细说明参见 [消息中心 API](../api/messages.md)。
