# 邮件外观

邮件模板采用 RenoP 的蓝色操作按钮、圆角卡片、中性色背景和系统字体。
站点名称显示在消息上方，验证码使用独立面板，附加详情与正文分隔。
纯文本版本包含相同的消息与操作链接。

## 选择预设

设置 `mail.template_style`，或在邮件设置页选择模板样式：

```yaml
mail:
  template_style: card
```

- `card`：留白充足的标准卡片。
- `compact`：缩小内容边距与标题字号。
- `notice`：带琥珀色顶边的标准卡片。

所有预设保留相同的场景标识和账号语言选择，不需要外部图片、字体、脚本或样式表。
基础外观使用内联颜色；收件客户端支持时，会应用响应式和深色模式规则。
用户文本仍会转义，操作链接必须属于已配置的实例。

## 预览与投递

管理员可在邮件设置页预览场景，无需实际发信。
GET /api/settings/mail/templates/:scene?style=card 返回主题、HTML 与纯文本。
预览按请求的 `Accept-Language` 选择语言，账号通知按收件人的已保存语言发送，缺省为英语。
预览使用示例值，不包含已保存的凭据。

模板变化在新邮件进入发送队列时生效，已排队邮件保留其任务中保存的已渲染内容。
投递限制、额度预留、状态检查以及不重试中断提交的规则保持不变。
提供商与队列配置见[邮件投递](mail.md)。
