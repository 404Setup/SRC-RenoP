# 简介

RenoP 是一个自托管的 Maven 仓库服务器。

- 支持 Release / Snapshot / Private 仓库
- 上游镜像代理（支持本地缓存）
- Web 管理界面：制品浏览、上传管理、用户管理、令牌管理、健康检查

RenoP 专注于私有部署，不提供公共多租户托管服务。

## 设计目标

| 目标           | 说明                                         |
|----------------|----------------------------------------------|
| 运维简单       | 单一二进制文件，配置文件存放在工作目录       |
| Maven 标准布局 | 遵循标准仓库路径规范，兼容所有 Maven 客户端  |
| 纯净无干扰     | 无广告、无遥测数据收集、完全免费             |

## 核心功能

- **仓库类型**：Release / Snapshot / Private 仓库（Maven 标准布局）
- **上游镜像**：配置上游 Maven 仓库代理，提供本地缓存与负缓存机制
- **Web 管理界面**：制品浏览与上传、用户管理、令牌管理、健康状态监控
- **存储后端**：支持本地磁盘或 S3 兼容对象存储
- **身份认证**：会话认证、Basic Auth、Bearer Token、上传令牌、仓库级权限控制
- **其他特性**：校验和生成、Javadoc 在线预览、自动更新、分块上传
