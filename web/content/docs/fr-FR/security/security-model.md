# Modèle de sécurité

- **Anonymous** : Lecture des dépôts PUBLIC uniquement
- **User** : Accès selon les permissions (`canview:{repo}`, `canupdate:{repo}`)
- **Manager / Admin** : Administration du système et des utilisateurs
