# API du registre Cargo

- `GET /{repo}/config.json`
- `PUT /{repo}/api/v1/crates/new`
- `GET /{repo}/api/v1/crates/:crate/:version/download`
- `DELETE /{repo}/api/v1/crates/:crate/:version/yank`
